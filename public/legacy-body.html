A PowerShell-generated CSV, or one-or-more .reg files from Intune Collect diagnostics.
Option A · PowerShell on the device
Full picture — HKLM 32-bit, HKLM 64-bit, and per-user HKCU. Use this when you have remote PowerShell or console access to the machine.
$paths = @(
  'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*',
  'HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\*'
)
$desktop = [Environment]::GetFolderPath("Desktop")
Get-ItemProperty -Path $paths -ErrorAction SilentlyContinue |
  Where-Object { $_.DisplayName } |
  Select-Object DisplayName, DisplayVersion, Publisher, InstallDate,
                UninstallString, QuietUninstallString, SystemComponent,
                PSChildName, @{n='RegistryPath';e={$_.PSPath -replace 'Microsoft.PowerShell.Core\\Registry::',''}} |
  Export-Csv -Path "$desktop\Uninstall-Export.csv" -NoTypeInformation -Encoding UTF8
Option B · Intune Collect diagnostics
HKLM only — the fastest path when you only have Intune access. Per-user HKCU is not in the diagnostics bundle, so the Per-user tile will show 0; use Option A if you need HKCU.
  1. In the Intune admin center, run Collect diagnostics on the target device.
  2. Download and extract the resulting ZIP.
  3. Drop both of these files into the dashboard:
    • (18) RegistryKey HKLM_Software_…_Uninstall export.reg
    • (21) RegistryKey HKLM_SOFTWARE_WOW6432Node_…_Uninstall export.reg

What is cached vs re-fetched
  • In-memory (this session) — each Intune sub-tab keeps its last Graph result until you click Refresh on that tab or switch customer/tenant (full reset). Switching browser tabs does not clear it.
  • sessionStorage — MSAL access tokens only (no refresh tokens across browser restarts).
  • localStorage — customers list, Claude/OpenRouter and xAI keys + model, Analyse provider, large-tenant toggles, error-analysis cache. Survives reloads; never uploaded as a blob to our servers (there are none).
  • Always live on demand — MAA approve/reject/complete, app/device deletes, script deploy, mail send, and any action after Cancel mid-walk (partial data stays until Refresh).
  • Long walks — Hardware device paging + RAM backfill, and Assignments multi-endpoint index, show Cancel while running. Cancel keeps whatever already arrived.
Choosing a model
Haiku 4.5 is the default — cheapest, fastest, and has its own rate-limit bucket so it won't conflict with other Anthropic API usage. Sufficient for error-code lookup and most MSI logs where the failure is a single obvious stack trace.
  • Haiku 4.5 — default. Most error codes and routine logs.
  • Sonnet 5 — escalate when Haiku misses something. Better at correlating timestamps across long IME logs and isolating root cause from noise. Intro pricing ($2/$10) through Aug 2026.
  • Opus 4.8 — reserve for cases where Sonnet gives up. The Opus 4.7+ tokenizer uses ~30% more tokens for the same text, so the effective cost gap is wider than headline pricing.
  • Fable 5 — Anthropic's most capable model, at 2× Opus pricing and higher latency. Last resort for logs nothing else can untangle.
Biggest cost lever: auto-trim logs before sending — grep for error/return-value lines + surrounding context cuts input tokens 80%+ with no quality loss.
Choosing a model
Grok 4.3 is the default — cheaper and enough for error-code lookup and most MSI logs, same reason Claude defaults to Haiku.
  • Grok 4.3 — default. $1.25 / $2.50 per MTok, 1M context. Routine error codes and trimmed logs.
  • Grok 4.6 — escalate for deeper / stuck logs ($2 / $6 per MTok under 200k prompt tokens).
